# ArsonistTimer

**ArsonistTimer — сжигай задачи, а не дедлайны.**

Контролируй своё время при помощи техники pomodoro: разбивай работу на короткие фокус-сессии, запускай таймер прямо на задачу и смотри, куда реально ушло время.

## Установка

Скачать приложение можно на странице [GitHub Releases](https://github.com/goryachev-maxim2003/ArsonistTimer/releases).

### Windows

1. Откройте последнюю версию в разделе Releases.
2. Скачайте файл `ArsonistTimer Setup ... .exe`.
3. Запустите установщик.
4. После установки приложение появится в меню «Пуск», а ярлык будет создан на рабочем столе.

Если Windows SmartScreen покажет предупреждение, это связано с тем, что сборка пока не подписана платным сертификатом разработчика.

### macOS

1. Откройте последнюю версию в разделе Releases.
2. Скачайте файл `ArsonistTimer-... .dmg`.
3. Откройте `.dmg` и перетащите ArsonistTimer в папку `Applications`.
4. Запускайте приложение из `Applications`, Launchpad или Dock.

Если macOS покажет предупреждение о неизвестном разработчике, нажмите правой кнопкой по приложению и выберите «Открыть». Для полностью бесшовной установки в будущем понадобится Apple Developer ID и notarization.

## Обновления

ArsonistTimer проверяет новые версии через GitHub Releases.

- Если доступна новая версия, приложение покажет окно с предложением обновиться.
- Во вкладке «Обновления» можно проверить обновления вручную.
- Там же будет отображаться описание изменений из GitHub Release.
- При обновлении задачи, проекты, статистика, настройки и история фокуса сохраняются.

Обновление заменяет только файлы приложения. Пользовательские данные хранятся отдельно в локальном профиле ArsonistTimer.

## Что такое техника pomodoro

Pomodoro — это способ работать короткими отрезками: обычно 25 минут фокуса, затем короткий перерыв. После нескольких помидоров делается длинный перерыв. Метод помогает не расплываться по задачам, легче начинать работу и честнее видеть, сколько времени ушло на дело.

В ArsonistTimer помидор привязан к конкретной задаче: запустил таймер, поработал, получил запись в статистике.

## Возможности

- Быстрое добавление задач: текст задачи и план в помидорах.
- Проекты как папки прямо на странице задач.
- Добавление одной или нескольких задач в проект.
- Сворачивание и раскрытие папок проектов с сохранением состояния.
- Таймер фокуса прямо в списке задач.
- Переключение активной задачи во время работы.
- Учет фактически потраченного времени по задачам.
- Завершение задачи с анимацией сгорания.
- Звуки таймера и отдельный звук сгорания задачи.
- Локальная статистика по дням, неделям и месяцам.
- Календарь фокуса с деталями выбранного дня.
- Журнал фокуса по дням и часам.
- График фокуса по дням с просмотром прошлых периодов.
- Прогноз выполнения всех задач или выбранных проектов.
- Настройки таймера, внешнего вида, дневной цели и звуков.

## Основные экраны

### Задачи

Главный экран приложения. Здесь можно добавлять задачи, запускать таймер, менять количество помидоров, завершать задачи, создавать проекты и раскладывать задачи по папкам.

Проекты остаются видимыми даже без задач. Если удалить проект, задачи из него перейдут в раздел без проекта.

### Статистика

Экран для анализа фокуса:

- календарь показывает, сколько времени было потрачено в разные дни;
- по выбранному дню видно, какие задачи выполнялись;
- есть сводки за день, неделю и месяц;
- журнал фокуса показывает работу по часам;
- график по дням масштабируется относительно максимального дневного фокуса за всё время.

### Прогноз

Показывает, когда будут закрыты текущие задачи:

- по дневному плану;
- по среднему темпу за неделю;
- по сегодняшнему темпу;
- для всех задач или только выбранных проектов.

### Обновления

Здесь можно проверить наличие новой версии, скачать обновление и посмотреть, что изменилось в релизе.

### Настройки

В настройках доступны длительность фокуса и перерывов, ручной или автоматический запуск следующего таймера, внешний вид, дневная цель в помидорах, громкость и выбор звуков.

## Локальное хранение данных

ArsonistTimer работает локально. Сервер, аккаунт и облако не нужны.

На компьютере пользователя сохраняются:

- задачи;
- проекты;
- фокус-сессии;
- статистика;
- настройки;
- состояние таймера.

При обновлении приложения эти данные не удаляются.
