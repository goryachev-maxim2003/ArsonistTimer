# ArsonistTimer

**ArsonistTimer** — локальное desktop-приложение для задач, проектов, фокус-таймера и статистики. Оно помогает планировать работу в помидорах, запускать таймер прямо на задачу, смотреть историю фокуса и прогнозировать, когда будут закрыты текущие задачи.

Приложение работает локально: задачи, проекты, настройки, история и статистика хранятся на компьютере пользователя.

## Возможности

- Быстрое добавление задач: текст задачи и план в помидорах.
- Проекты как папки прямо на странице задач.
- Создание проекта сразу с одной или несколькими задачами.
- Добавление нескольких задач в существующий проект через контекстное меню.
- Сворачивание и раскрытие папок проектов с сохранением состояния.
- Таймер фокуса прямо на странице задач.
- Переключение активной задачи во время фокуса.
- Учет фактически потраченного времени по задачам.
- Завершение задачи с анимацией сгорания.
- Звуки таймера и отдельный звук завершения задачи.
- Локальная статистика по дням, неделям и месяцам.
- Календарь фокуса с деталями выбранного дня.
- Журнал фокуса по дням и часам с навигацией по прошлым периодам.
- График фокуса по дням с просмотром прошлых 14-дневных периодов.
- Прогноз выполнения задач по дневному плану, среднему за неделю и темпу текущего дня.
- Фильтр прогноза по проектам с сохранением выбора.
- Настройки таймера, внешнего вида, дневной цели и звуков.

## Основные экраны

### Задачи

Главный экран приложения. Здесь можно:

- добавить задачу;
- указать плановое количество помидоров;
- запустить таймер на конкретную задачу;
- поставить таймер на паузу или остановить его;
- переключить таймер на другую задачу;
- завершить задачу;
- открыть меню задачи через `...` или ПКМ;
- создавать, раскрывать, скрывать и удалять проекты.

Проекты отображаются как папки. Если в проекте нет задач, папка всё равно остаётся видимой.

### Статистика

Экран для просмотра истории фокуса:

- календарь с количеством фокуса по дням;
- подробности выбранного дня;
- сводка за день, неделю и месяц;
- график фокуса по дням;
- журнал фокуса по часам;
- навигация по прошлым периодам.

График по дням масштабируется по максимуму фокуса за один день за всё время, чтобы разные периоды сравнивались честно.

### Прогноз

Показывает, за сколько дней можно закрыть текущие задачи:

- по дневному плану;
- по среднему темпу за неделю;
- по сегодняшнему темпу.

Можно выбрать все проекты или только отдельные проекты. Выбор фильтра сохраняется после перехода между вкладками и после перезапуска.

### Настройки

В настройках доступны:

- длительность фокуса;
- короткий и длинный перерыв;
- ручной или автоматический запуск следующего таймера;
- внешний вид и акцентный цвет;
- дневная цель в помидорах;
- громкость и мелодия таймера;
- громкость и проверка звука сгорания задачи.

## Локальное хранение данных

ArsonistTimer использует IndexedDB. Локально сохраняются:

- задачи;
- проекты;
- фокус-сессии;
- статистика;
- настройки;
- история таймера.

Данные не требуют сервера, аккаунта или облака.

## Запуск для разработки

```bash
npm install
npm run dev
```

Dev-сервер запускается на `127.0.0.1`.

## Сборка

```bash
npm run build
```

Готовый frontend попадает в папку `dist`.

## Запуск desktop-приложения

```bash
npm run app
```

Для повторного открытия без пересборки:

```bash
npm run app:open
```

Локальная desktop-сборка создаётся командой:

```bash
npm run package:local
```
